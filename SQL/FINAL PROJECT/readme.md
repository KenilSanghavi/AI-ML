# Student Course Management System (SQL)

## Overview

The **Student Course Management System** is a SQL-based database project developed using **MySQL**. It is designed to manage information related to students, courses, instructors, departments, and enrollments. The project demonstrates fundamental and advanced SQL concepts through practical database operations and queries.

This project is suitable for learning relational database design, SQL programming, and database management concepts.

---

## Features

- Student record management
- Course management
- Department management
- Instructor management
- Student enrollment management
- CRUD (Create, Read, Update, Delete) operations
- Data retrieval using joins
- Aggregate function queries
- Subqueries
- Date and string functions
- Window functions
- CASE statement implementation

---

## Database Tables

The database consists of the following tables:

- **Students**
- **Courses**
- **Departments**
- **Instructors**
- **Enrollments**

These tables are connected using primary keys and foreign keys to maintain relational integrity.

## Queries Included

The project includes SQL queries for:

- CRUD operations on all tables
- Retrieving students based on enrollment year
- Fetching department-wise courses
- Counting students enrolled in each course
- Finding students enrolled in multiple courses
- Calculating average course credits
- Department-wise student count
- INNER JOIN and LEFT JOIN operations
- Subquery-based data retrieval
- Extracting year from dates
- Concatenating instructor names
- Running total calculations
- Categorizing students as Senior or Junior
