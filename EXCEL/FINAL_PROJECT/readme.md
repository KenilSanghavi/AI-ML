Customer Transaction Analysis – Excel Project
📊 Project Overview

This project analyzes a customer transaction dataset containing 250 records using Microsoft Excel. The objective is to transform raw transaction data into meaningful insights through formulas, data analysis, Pivot Tables, charts, and an interactive dashboard.

🎯 Objectives
Analyze customer transactions and sales performance.
Identify high-value customers and frequently purchased products.
Analyze revenue by region, category, membership, and payment method.
Use Excel functions such as TODAY, NOW, DATEDIF, EOMONTH, FILTER, MATCH, and INDEX.
Perform What-If Analysis using Goal Seek and Scenario Manager.
Perform Linear Regression using the Data Analysis ToolPak.
Create Pivot Tables, Pivot Charts, Slicers, and Timelines.
Build a professional dashboard with important KPIs and visualizations.
📁 Workbook Sheets
Raw Data – Contains the original customer transaction dataset.
Analysis – Contains formulas, calculations, customer analysis, product analysis, and KPIs.
Visualizations – Contains charts and graphical analysis.
Dashboard – Provides an interactive summary of the overall business performance.
