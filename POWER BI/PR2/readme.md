# Healthcare Data Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **Healthcare Data Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes healthcare and patient data to identify patterns related to **patients, medical conditions, hospital admissions, billing, length of stay, insurance providers, and hospital revenue**.

The project provides interactive visualizations and filters that allow users to explore healthcare data from different perspectives.

---

## 🎯 Objectives

* Analyze the total number of patients.
* Understand healthcare billing and revenue.
* Analyze patient length of stay.
* Identify the distribution of medical conditions.
* Analyze hospital-wise revenue.
* Study monthly admission trends.
* Compare insurance provider coverage.
* Analyze billing across different departments and medical conditions.
* Provide detailed patient-level information.
* Enable interactive filtering for better data exploration.

---

## 📌 Dashboard Pages

### 1. Main Dashboard

The main dashboard provides an overall summary of the healthcare dataset.

It includes:

* Total Patient Count
* Total Billing Amount
* Average Billing Amount
* Average Length of Stay
* Patients by Medical Condition
* Hospital-wise Revenue
* Monthly Admission Trends
* Insurance Provider Coverage
* Admission Type Filter
* Medical Condition Filter
* Admission Year Filter

These visuals provide a quick overview of important healthcare KPIs and trends.

---

### 2. Patient Detail

The **Patient Detail** page provides patient-level information in a table format.

The table includes information such as:

* Patient Name
* Age
* Gender
* Medical Condition
* Department
* Admission Type
* Stay Category
* Length of Stay
* Billing Amount

Interactive slicers are provided for:

* Medical Condition
* Admission Type

This page allows users to filter and examine individual patient records.

---

### 3. Billing Analysis

The **Billing Analysis** page focuses on healthcare billing patterns.

It includes:

* Billing by Department
* Billing by Medical Condition
* Insurance Provider-wise Billing
* Admission Year Filter

This page helps analyze how billing varies across departments, medical conditions, and insurance providers.
